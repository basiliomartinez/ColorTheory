# ColorTheory

Práctica de comandos de Git. Primera experiencia en la creación de un repositorio, subirlo a GitHub y conectarlo a Netlify.

## 💻 Demo
👉 [Ver demo del proyecto](https://colortheory-bm.netlify.app/)

## 🛠 Herramientas utilizadas

- HTML
- CSS
- [Bootstrap v5.3](https://getbootstrap.com/docs/5.3/getting-started/introduction/)

## 🧪 Cómo probar este proyecto

Desde tu terminal:

1. Primero clonaremos este proyecto:
```
git clone
https://github.com/basiliomartinez/ColorTheory
```
2.  Se crea una carpeta con el nombre ColorTheory, ingresa al index.html y ejecuta ese archivo.
